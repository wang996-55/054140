# 个人工作台（Personal Workbench）

DeepSeek Harness 的本地插件：给 Harness 增加一个「工作台」侧栏面板，包含：

- **概览**：问候、数据卡片、最近生成画廊、快捷入口
- **生图**：电商模特图工作间（模特/背景/自定义提示词只能从「提示词库」点选、生图页不显示提示词全文也不提供输入框，只以按钮形式展示已保存的提示词，点按钮即加载该条，按钮上只显示条目名（悬停也不会显示全文），再点一次取消；旧版本手打过的提示词会在首次加载时自动转入提示词库，模板里的提示词随库内修改/删除同步，字段里出现库中不存在的提示词会标黄并给出「存入库」与「清除」；模特展示固定为「从脖子处裁切」的构图约束（以单段 JSON 覆盖写入提示词开头，列出必定出现/必定不会出现的部位）、商品参考图、多接口配置、2K/4K 分辨率、画幅+分辨率自动计算尺寸并写入提示词、商品保真、多并发生成队列、更换商品参考图后 5 秒自动提取商品描述（识别模型带「商品细节严格锁定」12 项规则，识别结果以 JSON 键值格式填入商品描述并进入提示词，商品描述自动前置「参考图唯一权威、仅作细节补充」声明））；图片请求默认使用**流式响应**（SSE，边生成边接收；可在设置里切换非流式，接口不支持流式时自动回退）；接口把参考图原样返回时自动重试并拒绝保存假结果
- **尺码表**：上传尺码表图片自动识别，生成带品牌 Logo、建议身高/体重（kg/斤可切换）的尺码表海报，可下载 PNG
- **本地持久化**：商品参考图、品牌 Logo、尺码表数据等保存在本机，刷新/重启后继续可用，只有手动删除/替换才会清除
- **打开输出目录**：已经在文件资源管理器打开了该目录时，直接切换并还原到已有窗口（最小化/隐藏也会恢复显示），不会重复开新窗口
- **设置**：多接口配置与切换、图片请求类型（流式/非流式）、模型一键拉取（生图接口与视觉接口都支持）、输出目录、商品图识别视觉模型（Harness 内置模型为默认，可添加多个第三方 OpenAI 兼容视觉接口并自由切换）、内置提示词编辑、外观强调色
- 模板库、提示词库、动作库等可复用内容（提示词库是可复用提示词的唯一创建/编辑入口，编辑直接在该条上展开；未保存的编辑不会因为返回生图页或切换标签而丢失，同一类别下不允许重复内容）

插件不修改 Harness 核心，可在「插件」页随时启停或卸载。

## 安装要求

- DeepSeek Harness 桌面版（Web UI / profile 模式），建议版本不低于 `0.2.1-rc.2`；
- 需要 Harness 自带的 `llm`、`attachments` 服务（用于「从商品图提取」「尺码表识别」等视觉功能）。缺少时其他功能仍可用。

## 安装方式（任选其一）

### 方式一：本地目录安装（推荐，最简单）

1. 把本项目文件夹放到任意位置，例如 `D:\plugins\personal-workbench`（文件夹内应有 `package.json`）；
2. 打开 Harness → 左侧「插件」页；
3. 点「添加插件」→ 选择「安装第三方插件」；
4. 在包名输入框粘贴项目文件夹的**绝对路径**（例如 `D:\plugins\personal-workbench`）；
5. 勾选信任提示，点「安装」，等待完成后启用；
6. 刷新页面（Ctrl+R），左侧栏出现「工作台」图标。

> 本地目录安装会以链接方式引用该文件夹，移动或删除文件夹会导致插件失效。

### 方式二：Git 地址安装

如果代码放在 GitHub/Gitee：

1. 在 Harness「插件」页 →「添加插件」→「安装第三方插件」；
2. 粘贴仓库地址，例如 `https://github.com/你的账号/personal-workbench.git`；
3. 安装并启用。

### 方式三：压缩包安装

1. 解压收到的插件压缩包（例如 `personal-workbench-1.1.21.zip`）；
2. 按「方式一」选择解压后的 `personal-workbench` 文件夹安装。

## 首次使用

1. 打开「工作台 → 设置」，填写你的图片接口地址（OpenAI 兼容）与 API Key，点「测试连接」后保存；可配置多个接口并备注名称；
2. 回到「生图」页：先在「提示词库」创建模特 / 背景 / 风格提示词，再回到生图页对应字段点选；上传商品参考图，选择画幅与分辨率，点「✦ 生成图片」；
3. 图片保存在设置里的输出目录；生成任务支持并发排队；
4. 「尺码表」页可上传现有尺码表截图自动识别，上传品牌 Logo 后生成海报并下载 PNG。

API Key 只保存在本机 Harness profile 目录，不会发送到浏览器；插件包本身不含任何密钥或用户数据。

## 更新

- **本地目录安装**：用新版文件覆盖原来的 `personal-workbench` 文件夹，然后在「插件」页把本插件关闭再启用（或重启 Harness），刷新页面即可；
- **Tarball / Git 安装**：在「插件」页卸载旧版，再按上面的方式安装新版。

## 常见问题

- **图片请求默认是流式响应**：工作台现在按「流式（SSE）」发起生图请求，边生成边接收，长耗时接口更稳。接口明确不支持流式（返回 unsupported / invalid stream）或返回无法识别的流时，会自动回退一次非流式请求；也可以在「设置 → 请求类型」里固定为「非流式响应」。
- **设置文件损坏 / 保存失败**：`settings.json` 无法解析时会优先从同目录的 `settings.json.bak` 自动恢复；如果连备份也不可用，工作台会保留原文件、给出提示并暂停保存，避免用默认配置覆盖掉接口和 Key。修复或恢复文件后重新打开工作台即可继续保存。
- **接口账户余额不足（insufficient balance）**：中转接口的账户余额/额度用完了。表现为单个任务还能偶尔成功、多并发时其余任务立刻失败。工作台会显示「余额不足」提示并停止剩余排队任务，避免整队报错；请到对应平台充值，或在「设置」里更换接口/模型。
- **多并发时偶发失败**：接口上游 5xx/429/超时/网络错误现在会自动重试一次；余额/鉴权类错误不重试并立即停止队列。
- **商品图提取想用第三方视觉模型**：「设置 → 商品图识别模型」里 Harness 内置模型是默认项，可添加多个第三方 OpenAI 兼容视觉接口（接口地址含 `/v1`、支持图片输入的模型名、API Key），点卡片即可自由切换；商品图提取和尺码表识别都会使用当前选中的接口。Key 只保存在本机配置里，不会回传浏览器。
- **生成结果就是自己上传的商品图**：个别中转接口在处理图片编辑请求失败时，会用「原样返回参考图」冒充成功。工作台从 1.1.2 起会自动识别这种返回：先自动重试一次，成功则正常保存；仍失败则报错且不保存假图。若反复出现，请在「设置」里更换接口或模型（例如 `gpt-image-2.5-flare`、`gpt-image-2`、`nano-banana-2.1-2k`）。

## 卸载

「插件」页找到「个人工作台」→ 关闭或卸载即可。
