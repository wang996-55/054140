# 个人工作台（Personal Workbench）

DeepSeek Harness 的本地插件：给 Harness 增加一个「工作台」侧栏面板，包含：

- **概览**：问候、数据卡片、最近生成画廊、快捷入口
- **生图**：电商模特图工作间（模特/背景提示词、商品参考图、多接口配置、2K/4K 分辨率、商品保真、多并发生成队列、商品图自动提取描述）
- **尺码表**：上传尺码表图片自动识别，生成带品牌 Logo、建议身高/体重（kg/斤可切换）的尺码表海报，可下载 PNG
- **本地持久化**：商品参考图、品牌 Logo、尺码表数据等保存在本机，刷新/重启后继续可用，只有手动删除/替换才会清除
- **设置**：多接口配置与切换、模型一键拉取、输出目录、内置提示词编辑、外观强调色
- 模板库、提示词库、动作库等可复用内容

插件不修改 Harness 核心，可在「插件」页随时启停或卸载。

## 安装要求

- DeepSeek Harness 桌面版（Web UI / profile 模式），建议版本不低于 `0.2.1-rc.2`；
- 需要 Harness 自带的 `llm`、`attachments` 服务（用于「从商品图提取」「尺码表识别」等视觉功能）。缺少时其他功能仍可用。

## 安装方式（任选其一）

### 方式一：本地目录安装（推荐，最简单）

1. 把本项目文件夹放到任意位置，例如 `D:\plugins\personal-workbench`（文件夹内应有 `package.json`）；
2. 打开 Harness → 左侧「插件」页；
3. 点「添加插件」→ 选择「安装第三方插件」；
4. 在包名输入框粘贴项目文件夹的**绝对路径**（例如 `D:\plugins\personal-workbench`）；
5. 勾选信任提示，点「安装」，等待完成后启用；
6. 刷新页面（Ctrl+R），左侧栏出现「工作台」图标。

> 本地目录安装会以链接方式引用该文件夹，移动或删除文件夹会导致插件失效。

### 方式二：Git 地址安装

如果代码放在 GitHub/Gitee：

1. 在 Harness「插件」页 →「添加插件」→「安装第三方插件」；
2. 粘贴仓库地址，例如 `https://github.com/你的账号/personal-workbench.git`；
3. 安装并启用。

### 方式三：压缩包安装

1. 解压收到的 `personal-workbench-1.1.0.zip`；
2. 按「方式一」选择解压后的 `personal-workbench` 文件夹安装。

## 首次使用

1. 打开「工作台 → 设置」，填写你的图片接口地址（OpenAI 兼容）与 API Key，点「测试连接」后保存；可配置多个接口并备注名称；
2. 回到「生图」页：填写模特提示词、背景提示词，上传商品参考图，选择画幅与分辨率，点「✦ 生成图片」；
3. 图片保存在设置里的输出目录；生成任务支持并发排队；
4. 「尺码表」页可上传现有尺码表截图自动识别，上传品牌 Logo 后生成海报并下载 PNG。

API Key 只保存在本机 Harness profile 目录，不会发送到浏览器；插件包本身不含任何密钥或用户数据。

## 更新

- **本地目录安装**：用新版文件覆盖原来的 `personal-workbench` 文件夹，然后在「插件」页把本插件关闭再启用（或重启 Harness），刷新页面即可；
- **Tarball / Git 安装**：在「插件」页卸载旧版，再按上面的方式安装新版。

## 卸载

「插件」页找到「个人工作台」→ 关闭或卸载即可。
